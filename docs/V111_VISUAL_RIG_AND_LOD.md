# V110–V111

Two-segment visual arm fit uses a stable elbow bend plane and the existing weapon pitch. No gameplay weapon transform or hitbox changes. Distance detail tiers hide only glove overlays and lower-leg/trouser overlays, retaining class equipment, weapon and facial silhouette. Near/mid/far thresholds include hysteresis. Real Three.js geometry, grip and LOD checks saved in scripts/check-soldier-real-geometry.mjs; WebGL and FPS acceptance remain pending.
